# Python - Everything is Object

This project explores how Python handles different types of objects: the
difference between mutable and immutable types, references, aliasing, identity
vs. equality, and how variables are passed to functions.

## Requirements

- Ubuntu 20.04 LTS, `python3` (version 3.8.5)
- Every Python file starts with `#!/usr/bin/python3`, is executable, and ends
  with a new line
- Code follows `pycodestyle` (version 2.7.*)
- Answer files (`.txt`) contain a single line, no shebang, ending with a new
  line

## Learning Objectives

- What is an object, a class, and an instance
- The difference between mutable and immutable objects
- What a reference, an assignment, and an alias are
- How to know if two variables are identical (`is`) or equal (`==`)
- How to display a variable's identifier with `id()` and its type with `type()`
- The built-in mutable and immutable types
- How Python passes variables to functions
