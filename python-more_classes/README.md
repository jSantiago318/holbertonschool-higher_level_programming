# python-more_classes

More Object-Oriented Programming in Python, building up a `Rectangle` class.

This project deepens the OOP concepts from `python-classes`:

- Properties (getters/setters) with validation
- Public instance attributes vs. private attributes
- Class attributes
- The special methods `__str__` and `__repr__`
- The special method `__del__`
- Static and class methods

## Tasks

- `0-rectangle.py` — Defines an empty class `Rectangle`.
- `1-rectangle.py` — Adds `width`/`height` properties with type/value validation.
