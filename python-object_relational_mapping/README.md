# Python - Object-relational mapping

Connecting Python to a MySQL database, first with the `MySQLdb` module (raw SQL)
and then with the `SQLAlchemy` ORM.

## Requirements

- Files interpreted with `python3` (3.8) on Ubuntu 20.04 LTS
- All files start with `#!/usr/bin/python3` and end with a new line
- Code follows `pycodestyle` (2.7.*)
- Modules connect to MySQL on `localhost` port 3306
- Code is not executed when imported
