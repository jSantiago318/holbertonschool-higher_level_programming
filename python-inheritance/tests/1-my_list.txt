==================
The ``1-my_list`` module
==================

Using ``MyList``
----------------

Import the class from the module:

    >>> MyList = __import__('1-my_list').MyList

``MyList`` is a subclass of ``list`` and starts empty:

    >>> my_list = MyList()
    >>> print(my_list)
    []
    >>> isinstance(my_list, list)
    True

It supports all the usual ``list`` operations:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

``print_sorted`` prints the elements in ascending order:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

It does not modify the original list:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

It works on an empty list:

    >>> empty = MyList()
    >>> empty.print_sorted()
    []

It works on a list with a single element:

    >>> single = MyList([42])
    >>> single.print_sorted()
    [42]

It handles negative numbers:

    >>> mixed = MyList([3, -1, 0, -7, 2])
    >>> mixed.print_sorted()
    [-7, -1, 0, 2, 3]
    >>> print(mixed)
    [3, -1, 0, -7, 2]

It handles duplicate values:

    >>> dups = MyList([5, 1, 5, 1, 3])
    >>> dups.print_sorted()
    [1, 1, 3, 5, 5]

It can be built directly from an existing list:

    >>> ready = MyList([2, 1])
    >>> print(ready)
    [2, 1]
    >>> ready.print_sorted()
    [1, 2]
