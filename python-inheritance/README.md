# Python - Inheritance

This directory contains tasks exploring **inheritance** in Python: how classes
derive behavior from parent classes, how to inspect objects, and how to build
custom class hierarchies with validation.

## Concepts covered

- Listing the attributes and methods of an object (`dir`)
- Class, instance, and subclass relationships (`isinstance`, `issubclass`,
  `type`, `__bases__`, `__subclasses__`)
- Defining subclasses and overriding methods
- Building a `BaseGeometry` hierarchy with input validation
- Custom exceptions and method overriding
