# python-classes

Introduction to Object-Oriented Programming (OOP) in Python.

This project covers the fundamentals of classes and objects:

- Defining classes and creating instances
- The special `__init__` method and `self`
- Public, protected, and private attributes
- Data abstraction, encapsulation, and information hiding
- Properties and the Pythonic way to write getters and setters
- The `__dict__` of classes and instances
